## 1. 数据来源与口径

- 来源：银行间债市发行人在**上海清算所**（shclearing.com.cn）逐年披露的**经审计合并年报**，FY2020–FY2025 六年均为**标准无保留意见**；FY2025 审计机构由信永中和变更为中审众环。
- `netInc` = **归属于母公司所有者**的净利润（json `netParent`），不是含少数股东的 `netInc`。
- `gross` 取年报毛利（= revenue − cogs，FY2022 存在 0.01 元级舍入差）；`sga` = sell + admin；`tax` = 所得税费用（**不含**税金及附加，站内无 `surcharge` 字段）。
- 一律取各年**自身年报「本年金额」**，不用次年年报的重述值——利润桥要求同一年「营收−成本−费用−税」闭合，混用重述值会与当年费用项冲突。
